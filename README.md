# Ready for What? — v1.7

A standalone Studio Bridge research exhibit about how students, teachers and employers read evidence about an emerging designer. Twelve cards remain available in the rack. Click or drag one into the machine, change viewpoint, reveal the missing context and pull the lever to print a question.

The introduction disappears once the activity begins, including after resetting the reader. Student views use checked anonymised interview extracts. Teacher views use learning prompts and labelled paraphrases from the supplied insight deck. Employer views have Studio, Product team and Agency switches with illustrative questions. The final reveal shows missing context instead of repeating the three views. Receipts carry one short follow-up question.

Viewpoint icons, simpler paper layouts and consistent reading typography reduce clutter. The original olive, brown and brass machine, drag-and-drop, lever, paper tear and optional sounds remain. All 32 image assets, fonts and code are embedded in index.html.

Interpretive prompts, conclusions and suggested pairings are labelled. The exhibit does not rank people or calculate readiness. Research trails, source notes and the historical wider-context chart state their evidence boundaries. Raw interview transcripts are not included in the website.

Published with GitHub Pages from main. The editable React project is supplied separately.
